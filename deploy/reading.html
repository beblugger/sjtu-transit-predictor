本版数据能表达什么

每个事件包含一个优选观测点。事件时间、角距、方位和高度均在这个点计算；其他位置需要重新计算。本版没有完整可见范围、地面中心线或经量化的误差带，不画推测的覆盖圆，也不提供百米可见保证。没有常驻后台定位和附近通知。

校区范围图使用本地经纬度等距近似并按纬度校正东西方向比例，用于校区尺度读图。经纬度按 WGS84 解释，不做 GCJ-02 偏移。底图来自导出的交大校区边界，尚无道路、建筑或在线瓦片；边界源坐标未独立测绘核验。参考位置距离采用 WGS84 椭球面零高度两点的 ECEF 弦长，校区范围内近似地面直线距离，不是步行距离。

视觉编码

  • 太阳使用深棕圆形，月球使用蓝色菱形；颜色和形状共同表达类别，不为每颗卫星分配一种颜色。
  • 标记填充相对当前设备时间分为 ≤6 h、≤24 h、≤48 h 和 >48 h，透明度分别为 1、0.65、0.4、0.2。边线保持不透明。历史事件使用最深填充，须结合列表的绝对时间读取。
  • 时间远近与可靠性分开。没有把透明度解释为概率或轨道误差。当前没有轨道协方差或经校准的位置误差模型，因此没有 1σ / 3σ 图层。
  • 地图仅显示当前列表页的最多 50 个点，地图文字只标注选中事件。重叠时可用列表逐个选择；点数量和深浅不是密度或概率热图。
  • 普通文字以 4.5:1 为最低对比度目标；必要的图形边线以 3:1 为目标。数字采用等宽数字，数字列右对齐，单位写在列标题中。选中状态另用边线和文字表达。

字段、时间与单位

字段含义
时间原始数据采用 UTC 的 ISO 8601 / RFC 3339 时间表示。界面默认北京时间 UTC+08:00，切换时区不会改变所选的实际时段。筛选区间包含起点、不包含终点，以最小角距时刻归属。CSV 时间始终为 UTC。
入凌 / 出凌 / 最小角距在导出的观测点计算。入出凌接触阈值采用最小角距附近的日月和卫星视半径。毫秒是数值计算结果的表示精度，不是预报的真实误差上限。
持续时间 (s)原始 duration_ms 除以 1000；原始毫秒字段为整数，可能存在不足一毫秒的截断。
高度角 / 方位角 (°)相对观测点几何地平线。方位角从北 0° 向东 90° 增加。未接入地形、建筑遮挡或现场折射修正。默认 15° 是可调整的界面筛选阈值，不是行业硬性标准。
斜距 (km)观测点到卫星的空间距离，不是卫星距地表的轨道高度。
角距 / 角直径 (″)″ 为角秒，1° = 3600″，不表示时间秒。最小角距为卫星中心与日/月中心的角距离。
卫星尺寸 (m)有来源的物理尺寸范围。标称角直径按最大已知跨度保守估计，实际投影受姿态影响；尺寸未知时显示“未知”，计算仅采用卫星中心穿过日/月视圆盘的条件。
观测点WGS84 纬度、经度和计算采用的观测高度。GeoJSON 坐标数组依 RFC 7946 为 [经度, 纬度]；表格明确分别标注。观测高度未接入地形测量，不等于现场实测海拔。
轨道历元 / 外推时长历元是轨道元素对应的时刻，不是下载时间。外推时长为事件时刻距历元的绝对时间差 (h)。超过六小时的轨道仍保留并标注。
生成 / 下载 / 检查 / 上游发布时间分别是预报生成、有效目录获取、主站最后请求及最后下载版本对应的上游发布时间。它们不能互相替代。“未知 / 尚未记录”不表示最新。
未知值未知不按 0 处理。CSV 未知数值为空，JSON 为 null。勾选“保留尺寸未知”时，此类事件不受最小角直径数值限制。

天气评分

天气为校区参考位置的缓存预报，不是每个观测点的现场测量。P0、P3、P12 分别表达事件时刻、±3 小时和 ±12 小时窗口内，算法对各模型集合成员晴朗条件的统计。各模型评分为三项的几何平均，再综合 ECMWF / GFS 模型。判定还使用模型分歧和运行间变化；提前量对应不同阈值。

这些是模型指标，不是经真实观测校准的凌星观测成功概率，也不是轨道预测置信度。天气不可用时界面不展示原始占位零值为有效评分；原始 JSON 保留原数据。所有几何事件默认保留，不因天气或卫星地影排除。

依据及适用范围

以下来源指导本项目，并不意味着本页面已获认证或所有项目规则均来自正式标准。

  • WCAG 2.2：对比度、键盘操作、信息不只依赖颜色。属于正式 Web 推荐标准。
  • ColorBrewer：类别数据与有序数值采用不同视觉编码。本项目使用自选的固定深色类别色，并非宣称采用某套原版调色板。
  • Crameri 等，The misuse of colour in science communication：避免彩虹渐变、感知不均匀及色觉障碍造成的误读。
  • UCGIS Typography：地图文字层级和标签与对象的明确对应。
  • IOTA / OccultWatcher：地图、观测位置和事件列表的联动参考。
  • Lucy 掩星地图指南：区分中心线、几何边界和误差边界；目前后端未输出这些几何量，因此不绘制替代图形。
  • RFC 3339、RFC 7946、RFC 4180：分别作为时间、GeoJSON、CSV 的交换格式依据；CSV 增加 UTF-8 BOM 以方便电子表格读取，对公式开头的文本做转义，原始 JSON 保持不变。
