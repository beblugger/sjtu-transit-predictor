本版数据能表达什么

后端对日月与卫星的角偏差反解地面可见区域，覆盖闵行校区及邻近图示范围。区域表示这次凌星经过期间，各位置分别在各自时刻可能看到凌星；不是某个瞬间的共同覆盖，也不是卫星正下方的地面轨迹。只算导出的固定观测高度，未加入地形、楼顶或建筑遮挡。

反解以局部二维角偏差 g(p,t) 为基础，展开为 g ≈ g₀ + J·Δp + v·Δt。令 n 垂直于 v，消去时间后求 |n·(g₀ + J·Δp)| ≤ 日月视半径 + 卫星视半径。等号给出接触边界，等式 n·(g₀ + J·Δp)=0 给出中心线；最近接时刻也随位置由展开式求出。尺寸未知时卫星视半径取零，表示卫星中心穿入日月圆盘的区域。

使用 WGS84 椭球曲面上的观测点进行角几何计算，以校区局部米制坐标表达一阶反解，再转换回 WGS84 GeoJSON。接触线、校区顶点和内部位置用完整 SGP4 与日月星历回算。若接触边界采样偏差超过 5 m，就分片重新展开；无法收敛则构建失败，保留上版数据。5 m 是采样检查的数值目标，不是全域严格误差界，也不是 TLE 的真实轨道误差。后者尚未量化，不能画成概率误差带。

同一事件可能覆盖全校区，中心线也可能在校外；显示整个校区并不表示使用任意缓冲圆。详情保留内部计算位置的精确数值时间及采样回算偏差。位置距离针对图示计算范围内的区域。可开启附近通知：距可见区不超过 100 米、未来 10 分钟内提醒，使用当地近似时刻；在可见区外使用导出观测点时刻。自动更新、附近通知、设备位置跟随可分别开关。系统挂起或关闭 App 后无法保证更新与通知。

图示使用 Web Mercator，输入科学区域和位置为 WGS84，不混入 GCJ-02。建筑与校区边界来自交大地图；其校园 WMS 声明 CRS:84 / EPSG:3857，建筑接口自身未声明基准或测量精度，未作独立测绘核验。位置距离在后端的局部米制坐标中计算；超出图示计算范围时不作局部距离推断。区域内为 0，区域外为到最近边界的近似直线距离，不是步行距离。详情中的“距可见区”显示“区域内”时，仅表示该位置的坐标落在该事件的可见区域几何内；它不包含天气、建筑遮挡或轨道误差判断。

校内底图保留交大原站的配色、道路和文字，由浏览器按当前视图加载源站同款 WMS 分块并叠加建筑矢量轮廓，不使用整张预渲染快照；道路和文字并非原生矢量。校外随视图在 z14–z19 间选择清晰的 OSM 瓦片，最多缓存 64 张、12 MiB，不预取其他层级或区域。地图可拖动和缩放，底图始终开启；点击区域不切换事件。事件、校区和天气数据按 manifest 哈希读取。

视觉编码

  • 选中事件使用独立蓝色，邻近事件使用灰色；地图不绘制事件序号或推荐点。区域用浅填充，图例中的“接触边界”用实线，中心线用同色虚线；尺寸未知时该边界表示卫星中心穿入日月圆盘的条件，不是物理轮廓接触线。
  • 可见区域填充相对当前设备时间分为 ≤6 h、≤24 h、≤48 h 和 >48 h，深浅系数分别为 1、0.65、0.4、0.2，选中事件填充透明度固定为 0.28，其他为时间系数乘以 0.07。边线保持不透明。
  • 时间远近与可靠性分开。没有把透明度解释为概率或轨道误差。当前没有轨道协方差或经校准的位置误差模型，因此没有 1σ / 3σ 图层。
  • 时间范围默认覆盖整份数据的完整起止时段；filterEvents 静默排除已发生事件，因此列表、筛选结果和默认地图叠加只出现未来事件，“全部数据覆盖时段”仍保留原时段。未来 6 / 24 / 96 小时仅在主动选择时收窄，并受数据结束时间限制。默认选择最早的尚未发生事件，固定叠加筛选结果按时间排序的前后各最多两条，两端不补足；相邻事件跨分页。列表每页最多 10 条。多区域重叠只是多个几何集合，不表示密度或概率。导出数据仍保留覆盖内全部事件；已发生事件若仍存在于当前或离线缓存的数据快照中，可通过事件链接查看详情。
  • 普通文字以 4.5:1 为最低对比度目标；必要的图形边线以 3:1 为目标。数字采用等宽数字，数字列右对齐，单位写在列标题中。选中状态另用边线和文字表达。

字段、时间与单位

字段含义
时间原始数据采用 UTC 的 ISO 8601 / RFC 3339 时间表示。界面固定采用 CST（中国标准时间，UTC+08:00），以最小角距时刻归属筛选时段。
最近时刻卫星中心与日/月中心角距最小的时刻，在导出的观测点计算。界面仅显示最近时刻，入凌、出凌仍保留在原始数据中。毫秒是数值计算结果的表示精度，不是预报的真实误差上限。
持续时间 (s)原始 duration_ms 除以 1000；原始毫秒字段为整数，可能存在不足一毫秒的截断。
高度角 / 方位角 (°)相对观测点几何地平线。方位角从北 0° 向东 90° 增加。未接入地形、建筑遮挡或现场折射修正。默认 15° 是可调整的界面筛选阈值，不是行业硬性标准。
距离 (km)观测点到卫星的空间距离，不是卫星距地表的轨道高度。
角距 / 角直径 (″)″ 为角秒，1° = 3600″，不表示时间秒。最小角距为卫星中心与日/月中心的角距离。
卫星尺寸 (m)优先采用有来源的物理跨度（ISS 最大跨度 109 m）。缺少物理跨度但有 Stellarium 雷达截面积 RCS 时，以 D = 2√(RCS/π) 估计等效圆直径，明确标为“RCS 等效估算”、低可信度；它不是卫星真实物理尺寸或光学轮廓，不生成虚假的尺寸范围。角半径 = atan(D/(2r))，角直径 = 2 × 角半径，r 为观测者到卫星的距离。候选筛选、接触时刻、可见区与界面使用同一半径。两类数据都缺失时保留未知，采用卫星中心穿过日/月视圆盘的条件，不将 0.1″ 显示占位值当作真实尺寸。
反解区域与局部时刻visibility.geometry 为图示范围内可见区，visibility.centerline 为中心线，visibility.boundaries 为真实接触边界；calculation_domain 表示计算范围，不绘制其裁切边缘；campus_geometry / campus_area_m2 单独保存校内交集和面积。models 保存局部展开、时间梯度和单位。maximum_sampled_boundary_error_m / maximum_sampled_time_error_s 是采样回算偏差；没有接触边界穿过校区时前者可为 null。orbital_uncertainty_m=null 表示真实轨道误差尚未量化。
观测点WGS84 纬度、经度和约 10 m 的 GNSS 椭球高。GeoJSON 坐标数组依 RFC 7946 为 [经度, 纬度]；表格明确分别标注。观测高度未接入地形测量，不等于现场实测海拔。
轨道历元 / 外推时长历元是轨道元素对应的时刻，不是下载时间。外推时长为事件时刻距历元的绝对时间差 (h)。超过六小时的轨道仍保留并标注。
生成 / 下载 / 检查 / 上游发布时间分别是预报生成、有效目录获取、主站最后请求及最后下载版本对应的上游发布时间。它们不能互相替代。“未知 / 尚未记录”不表示最新。
未知值未知不按 0 处理。构建数据中未知数值为 null。尺寸筛选暂未开放，未知尺寸事件保留；详情中未知字段不显示。
亮度 / 受光状态最近时刻的受光状态由 Skyfield / DE421 判断；在地影中直接标注。受光时采用 Stellarium 的 Starlink 经验、标准星等与相位修正、雷达截面积近似模型，按此顺序选择有依据的估算，显示“约 X.X 等”。星等越小越亮，未计大气消光、耀斑与半影增量，不代表肉眼可见；太阳凌星时尤其不能用星等代替圆盘背景下的可见性。缺少参数时显示“暂无星等估计”，不用默认星等补值。模型和参数来源见Stellarium 源码及来源与许可。

天气评分

天气为校区位置的缓存预报，不是每个观测点的现场测量。P0、P3、P12 分别表达事件时刻、±3 小时和 ±12 小时窗口内，算法对各模型集合成员晴朗条件的统计。各模型评分为三项的几何平均，再综合 ECMWF / GFS 模型。判定还使用模型分歧和运行间变化；提前量对应不同阈值。

这些是模型指标，不是经真实观测校准的凌星观测成功概率，也不是轨道预测置信度。天气不可用时界面不展示原始占位零值为有效评分；原始 JSON 保留原数据。后端保留所有几何事件，不因天气或卫星地影排除。界面以全部、晴天、阴天三个选项卡筛选。

依据及适用范围

以下来源指导本项目，并不意味着本页面已获认证或所有项目规则均来自正式标准。

  • WCAG 2.2：对比度、键盘操作、信息不只依赖颜色。属于正式 Web 推荐标准。
  • ColorBrewer：类别数据与有序数值采用不同视觉编码。本项目使用自选的固定深色类别色，并非宣称采用某套原版调色板。
  • Crameri 等，The misuse of colour in science communication：避免彩虹渐变、感知不均匀及色觉障碍造成的误读。
  • UCGIS Typography：地图文字层级和标签与对象的明确对应。
  • IOTA / OccultWatcher：地图、观测位置和事件列表的联动参考。
  • Lucy 掩星地图指南：区分中心线、几何边界和误差边界；本项目绘制几何反解区域与中心线，不虚构未量化的轨道误差带。
  • RFC 3339、RFC 7946：分别作为时间与 GeoJSON 的交换格式依据。
